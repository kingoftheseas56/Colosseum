# Colosseum Harness Desktop

Slice 1 is the bare Electron cockpit for the existing Python Colosseum Harness.

Current scope:
- Electron + React + TypeScript + Vite
- secure main/preload/renderer separation
- custom Windows chrome
- task/workspace/inspector/status shell
- persistent window and shell geometry
- tests and packaged Windows smoke

Not wired yet: Codex App Server, Python Harness commands, task SQLite, Monaco, Git actions, Lanista, or behavioral directives.
