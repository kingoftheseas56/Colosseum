## What's new in 1.2.0

- **Personal Collections:** Create private shelves across supported media, add notes, and set your own order.
- **Manga and Manhwa:** More discovery shelves, a Manhwa category, and improved language-aware reading progress and Long Strip resume.
- **Extensions:** Preview and install add-ons from URLs, then manage their settings and availability.
- **Downloads and Vault:** Better synchronization, bulk deletion, and protection for manually added local files.
- **Windows:** Optional DLNA sharing and experimental AniList integration. Live AniList sign-in and sync are not yet release-qualified.

Colosseum has dedicated readers and video playback, shared Continue, Downloads, and sessions. Local use does not require a Colosseum account. [Explore the interactive Tributes](https://getcolosseum.world/).

## Notes

- Linux is qualified on **Ubuntu 24.04 amd64**; updates are manual.
- **Feria and Vinyl** remain unavailable in the 1.2.0 installers.
- Colosseum is a client and does not host media. External sources are independent services.
