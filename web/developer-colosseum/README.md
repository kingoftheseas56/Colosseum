# Web Colosseum — web half

The authority is `CONTRACT.md` v1.1, in `Preflight-Architect/arcs/54-developer-web-colosseum/`. This folder is
its web half. There is no build step and no frameworks: plain scripts loaded in order by `index.html`,
sharing one namespace, `window.CW`.

| Path | Owner | What |
|---|---|---|
| `index.html`, `app.js` | Claude | the single entry and the bootstrap. The adapter is picked automatically. |
| `core/port.js` | Claude | THE CONTRACT: subscribe/more/act/onShell, validation, stale-event dropping |
| `core/router.js` | Claude | web-internal navigation (home, world+tab, seeAll, search, back) |
| `core/focus.js` | Claude | the one focus engine (TV rules, focus restore by `data-key`, `[data-arrows]` hook) |
| `core/shell.js` | Claude | wallpaper, TopBar, toast, covered state, and mounting the one visible surface |
| `components/` | Claude | `dom` (h, face), `cards`, `section` (all layouts + states + sync), `tab-bar` |
| `styles/` | Claude | `tokens.css` (Theme.qml block generated by `dev/gen_tokens.py`), `shell.css`, `components.css` |
| `adapters/` | Claude | `qwebchannel.js` (real), `fixture.js` (replays recorded events) |
| `surfaces/reference/` | Claude | the generic fallback surface for every route, and the shape to copy |
| `surfaces/<name>/surface.js` + `surface.css` | **one swarm agent each** | home, theatre, tankoban, biblio, seeall, search. Already linked from `index.html`. |

## Run

- **Inside Colosseum** (`COLOSSEUM_WEBUI=1`), the page talks to `ColosseumWebBridge` over QWebChannel.
- **In a browser**, serve the repo root (`python -m http.server 8931`) and open
  `/web/developer-colosseum/index.html`. With no `qt`, the page replays `fixtures/` (recorded; local only). A
  dashed dev panel lets you rehearse **low power** and **covered**. `?power=low` works on the real app too.
- **Core self-test:** `/web/developer-colosseum/dev/selftest.html`. The tab title says PASS or FAIL.

## Writing a surface (swarm)

```js
(function (CW) {
  CW.router.register('theatre', {
    mount(el, route, env) {               // route = { name:'world', world:'Theatre', tab }
      const pane = CW.h('div.world-pane'); el.appendChild(pane);
      let sub = env.port.subscribe('world', { world: route.world, tab: route.tab },
        ev => CW.section.sync(pane, ev, { open: env.open, forget: env.forget, seeAll: env.seeAll,
                                          more: s => env.more(sub, s) }));
      return { update(r) { /* tab change */ }, unmount() { sub.close(); } };
    }
  });
})(window.CW);
```

Rules (CONTRACT §4, §8):
- Use only `env`, `CW.h`, `CW.cards`, `CW.section`, `CW.tabBar` and `var(--tokens)`.
- Never read `item.ref`.
- Never handle arrow keys. Mark focusables with `data-focus` and items with `data-key`.
- Every section shows loading, empty and error states.
- Need a component, field or action that doesn't exist? File a request; never edit core.
