## Fixture and platform boundaries
This is a source-derived HTML UI recreation, not a compiled QML app or port of its C++ engines. Account/authentication, device approval, sync, tracker import/export, downloads, updates, filesystem actions and media playback operate on inert in-memory fixtures. Do not enter real passwords, keys, tokens or personal details. No providers are contacted.

Reader page artwork is original labeled sample content. Reader text uses public-domain excerpts, not the copyrighted catalogue book. Catalogue/search data are finite local samples; native file pickers, shaders, 3D universes, timing/ranking algorithms, DRM and service engines are not reproduced. Native 3D surfaces use labeled 2D approximations; wallpaper animation is a static preview. Review each manifest's explicit limitations.

Verification is Linux Chromium and Firefox only. Windows-native behavior and the compiled native application are untested. Browser form controls and fonts may differ by platform. Firefox shows sharper backgrounds through some frosted surfaces, including Home Continue cards and the Extensions tray, while Chromium renders frosted blur; this is a presentation limitation, not a runtime failure. No cause is claimed. See TEST-RESULTS.md for the final measured results, including Firefox font metadata warnings.

Original source artwork, marks and provenance notices remain in assets. No live site or production application is modified by this downloadable mock.
