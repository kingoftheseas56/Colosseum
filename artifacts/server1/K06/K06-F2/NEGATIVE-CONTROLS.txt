K06-F2 behavioral mutation controls

Each tracked patch under `mutations/` is applied alone by `run_mutations.ps1`
to an isolated Git archive plus candidate overlay. The runner rebuilds the real
K06 binary, requires a nonzero focused CTest result containing the named
assertion, reverses the patch, and preserves raw build/CTest logs in its unique
scratch run directory.

1. Omit restored committed=true.
   Rejected: valid persisted first piece restores verified and committed only.

2. Accept an existing destination without checking its required byte length.
   Rejected: short physical destination invalidates persisted true bit.

3. Validate disk bytes even when the persisted bitmap bit is false.
   Rejected: physical bytes never promote a persisted false bit.

4. Restore assembled=true together with verified and committed.
   Rejected: valid persisted first piece restores verified and committed only.

5. Clear invalid bits only in memory and omit the single terminal bitmap persist.
   Rejected: missing-destination invalidation is persisted.

6. Skip complete logical-coverage validation.
   Rejected: logical destination gap invalidates persisted true bit.

7. Skip the staged memory-first read branch.
   Rejected: staged bytes remain the memory-first read source.

8. Restore the former silent bitmap persistence implementation by removing its
   open, write, and flush failure reporting.
   Rejected: bitmap persistence reports destination-open failure.

Result: 8/8 exact, reproducible behavioral mutations rejected. See
`MUTATION-RESULTS.txt` for commands, exit codes, and raw failure excerpts.
