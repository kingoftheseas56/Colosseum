## Shared core

The executable composes native owners in [native/main.cpp:418](https://github.com/kingoftheseas56/Colosseum/blob/5c4d9ffe1a17ff544d19e684bee9c1676ba5ee49/native/main.cpp#L418) and loads [qml/Main.qml:1](https://github.com/kingoftheseas56/Colosseum/blob/5c4d9ffe1a17ff544d19e684bee9c1676ba5ee49/qml/Main.qml#L1). QML owns navigation and interaction; existing JavaScript provider/catalogue glue remains part of the architecture. The five product worlds are Theatre, Tankoban, Biblio, Universes and Vault; Feria and Vinyl are gated development surfaces ([AGENTS.md:10](https://github.com/kingoftheseas56/Colosseum/blob/5c4d9ffe1a17ff544d19e684bee9c1676ba5ee49/AGENTS.md#L10); [native/CMakeLists.txt:27](https://github.com/kingoftheseas56/Colosseum/blob/5c4d9ffe1a17ff544d19e684bee9c1676ba5ee49/native/CMakeLists.txt#L27)).
