# Original synthetic hardware-profiler inputs

## Shipped behavior

The native service embeds an explicitly identified Colosseum-generated sample
set, so normal profiling does not depend on an external source bundle. The
reproduction script creates ignored intermediate `assets/` files. An explicit
external pinned-oracle sample mode remains available for exact M934 comparisons.
The generated files are not byte-identical replacements for Stremio's samples.

The native service embeds the generated set. Original source samples and their
notice files are excluded from this distribution.

## Origin and intended licensing

`generate.py` creates black frames and digital silence directly with FFmpeg's
`color` and `anullsrc` sources. No images, recordings, source sample media, fonts,
user media, public media, or other input asset files are read by the generator.
The generator, manifest and synthetic samples are provided under the existing
Colosseum MIT license in `tools/server_lab/profiler_samples/LICENSE`, to the extent applicable rights exist.
This does not assert exclusive ownership/copyrightability of black frames or
silence and does not relicense FFmpeg, libx265, or any other tool.

The GPL FAQ distinguishes a program's output from its code unless output embeds
copyrighted program material: https://www.gnu.org/licenses/gpl-faq.en.html#GPLOutput
FFmpeg separately documents its software licensing and warns that codec patent
questions depend on jurisdiction: https://ffmpeg.org/legal.html

These facts support using an independently generated fixture set rather than
copying ambiguously licensed source media. They are not a legal opinion or a
guarantee of copyright or codec-patent clearance. No FFmpeg binary is included in this asset package.

## Functional contract and deliberate difference

M805 uses `hevc.mkv` to test video decoding/encoding and `ac3-2chan.wav` to test
applicable audio profiles. It requests the normal HLS route with an explicit
profile and `maxWidth=1200`, then destroys the converter. M934 also serves
`aac-6chan.wav`. The generated set keeps those names, containers, MIME types,
codecs, dimensions, sample rates and channel layouts. Its pictures/audio are
synthetic, its compressed bytes/hashes differ, and audio durations differ.

- HEVC: black 1920x960 YUV420P, 25 fps, 0.2 seconds, Matroska.
- AC-3: digital silence, stereo, 44100 Hz, WAV, requested 0.25 seconds
  (codec frame padding affects actual duration).
- AAC: digital silence, 5.1 / six channels, 44100 Hz, WAV, requested 0.25 seconds
  (codec priming/padding affects actual duration).

The dimensions ensure M805's width cap exercises scaling rather than testing
only a tiny frame. Profile names or encoder listings alone never count as
hardware support. A profile is reported only after the existing real HLS
conversion succeeds. This machine reported no viable hardware profiles.

## Reproduction and qualification

From the repository root:

    python3 tools/server_lab/profiler_samples/generate.py
    python3 tools/server_lab/profiler_samples/package_include.py

The recorded build produced repeatable hashes. Different FFmpeg/libx265 versions
may change bytes; inspect manifest changes rather than claiming cross-version
byte reproducibility. The include contains only the generated set.

`ROOT-generated-samples-live` verifies HTTP hashes/MIME, ffprobe, full source
decode, and software HLS init/segment decode for all three samples. It checks
HEVC-to-H.264 scaling to 1200x600 and AAC output channel counts/sample rates,
confirms that real profiling does not interrupt playback, and exercises the
production application composition with no external sample directory.

`ROOT-profiler-samples-fixtures` also checks the default generated bytes, unknown
sample paths and rejection of generated files in an explicit pinned directory.
The existing differential, no-assets, real-loopback and repeated/overlapping
playback-isolation tests remain enabled. Hardware profiling still requires a
successful real conversion with an actual candidate profile; software conversion
is not proof of GPU support.

Qualification on Linux with FFmpeg 7.1.5 reproduced the manifest and embedded
include byte-for-byte, decoded every input/output, and passed all six focused
sample/profiler tests. No viable hardware profile was available. The packaging
script rejects altered asset bytes even when Python optimization is enabled.

Explicit external directories continue to require the original M934 hashes.
ExternalPinnedOnly with no directory returns 404, preserving missing-assets tests.
The pinned-oracle tests extract original bytes only into disposable directories.
No original RootSamples.inc or upstream copied media is part of this change.
