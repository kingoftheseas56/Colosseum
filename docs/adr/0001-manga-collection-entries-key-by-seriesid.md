# Manga Collection entries key by seriesId, not title

Manga Collection entries have always saved `id = seriesTitle` ([MangaSeries.qml](../../qml/MangaSeries.qml)), while Progress records for the same series key by the real `seriesId` ([ComicReaderState.js](../../qml/comicreader/ComicReaderState.js)). This blocked joining a saved manga series to its reading progress for the incoming Library tab. Going forward, `collectionEntry()` saves `id = seriesId` (title moves to the `title` field, where it already lived). Existing title-keyed entries are left as-is rather than migrated — saved-entry volume is small (personal use), so the Library row engine falls back to a title-based Progress lookup when a direct `seriesId` lookup misses, instead of taking on migration risk for little benefit.
