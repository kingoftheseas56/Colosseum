# Colosseum 1.1.6

Colosseum 1.1.6 focuses on keyboard-first navigation, multilingual Tankoban chapter sources, account and session reliability, responsiveness, and playback recovery. The Windows installer remains the stable release artifact; Linux continues on its separate beta qualification track.

## Important: one-time manual update required

Colosseum 1.1.6 establishes a new Ed25519 update-signing trust root because the private signing key used by 1.1.5 is no longer available. If you are on 1.1.5 or earlier, download and run the 1.1.6 Windows installer manually once. The older updater cannot authenticate the new key and intentionally fails closed.

After 1.1.6 is installed, automatic updates resume normally for releases signed by the new production key. Signature verification remains enforced throughout the transition.

## Keyboard navigation

Arrow-key navigation now works more naturally across Colosseum's shell, worlds, catalogues, account pages, settings, readers, and player controls. Focus follows the visible layout and can continue through overflowing or scrollable content instead of stopping at the edge of the viewport.

Focus return, scrolling, carousels, overlays, and long or virtualized lists have also been hardened. Enter remains the primary action, Escape backs out by one level, and Tab remains available as secondary traversal.

## Tankoyomi multilingual chapter sources

Tankoban chapter mode now supports persistent multilingual provider configuration with safer language routing and fallback behavior. Source matching and page-image validation are more reliable, reducing cases where a weak or broken provider can interfere with a better source.

Metadata and image loading also have improved IPv4 fallback for networks where broken IPv6 routes would otherwise make a healthy provider appear unavailable.

## Accounts and sync

Remembered account sessions now persist more reliably across normal launches. Duplicate desktop instances are prevented from racing session refresh, and stale recovery approvals are invalidated more aggressively.

Cross-device profile, activity, history, and recovery state are also more durable and better protected against interrupted or conflicting updates.

## Responsiveness and playback

More recurring work has been moved away from the main interface thread, unnecessary hidden-world activity has been reduced, and background scheduling has been tightened to keep navigation and interaction responsive.

The bundled Stremio runtime startup path has also been hardened so Theatre can recover its stream server after a failed launch instead of remaining stuck.

## Download

`Colosseum-1.1.6-setup.exe` is the Windows installer for this release.
