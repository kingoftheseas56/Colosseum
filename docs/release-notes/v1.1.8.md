# Colosseum 1.1.8

Connect your Trakt, SIMKL or MyAnimeList account directly, without a Stremio account.

- **Trakt and SIMKL:** direct device-code sign-in. The Stremio-linked Trakt path still works alongside direct Trakt.
- **MyAnimeList:** sign-in inside the app, with **Open in browser instead** available when a provider such as Google refuses an embedded login.
- **Discover:** an add-on catalogue sidebar and row index, plus shared row sidebars.
- **World feel:** smoother scrolling, improved glass, keyboard flow, and a docked tab bar.
- **Add-ons:** configure supported add-ons inside the app.
- **Tankoban:** series with no volume data open in Chapter Mode.

Trakt's token broker runs on Render's free tier and sleeps when idle; the first sign-in can take up to a minute.

Live account checks confirmed Trakt and SIMKL sign-in and the MyAnimeList login page loading. Completed imports, progress exports, live scrobbling, and disconnect have not been verified with real accounts. AniList remains Coming soon.

## Updating

From 1.1.6 or 1.1.7, update normally. From 1.1.5 or earlier, install 1.1.8 manually once because the updater signing trust root changed in 1.1.6.

Download: `Colosseum-1.1.8-setup.exe`. The stable installer is for Windows 10/11. A separate Linux alpha targets Ubuntu 24.04 x86_64 with X11, including WSL2/WSLg; direct trackers are Windows-only for now.
