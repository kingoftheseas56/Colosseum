# Colosseum 1.3.0

Nuvio joins Theatre in this desktop release, alongside new Tributes, opt-in Live Reading, and fixes to Theatre and Universes.

## Nuvio in Theatre

- Connect a Nuvio account as an optional Theatre sync provider. Review imports before choosing the primary Theatre provider; Colosseum sign-in remains separate.
- On Windows and Linux, opt in to native Nuvio plugin repositories and browse their Theatre sources. Results and playback availability depend on each provider. Native Nuvio plugins are not included on macOS.
- Nuvio profiles, Theatre removals, Next Up dismissals, and device-code sign-in have dedicated integration changes in this release. This is not a guarantee of every provider or account journey.

## Tributes and reading

- Open the Marvel Infinity Gauntlet Tribute and the Dexter Tribute from their franchise experiences.
- Enable Live Reading in Tankoban Chapter Mode to read available pages while a manga chapter downloads. It is opt-in; ordinary completed-chapter reading remains available.

## Theatre and Universes

- The series season bar and episode scrolling are repaired.
- Universe comic pages now list their releases.
- Universes shows the shell wallpaper while the catalogue opens, with adjusted tab pills and shared icon tooltips.

## Feedback and Extensions

- Send reports, feature requests, and Universe requests through the in-app forms.
- Browse compact Extensions shelves and review Theatre account imports in a clearer preview.

## Downloads and updating

- **Windows 10/11:** run `Colosseum-1.3.0-setup.exe`. Version 1.2.0 uses the signed in-app Windows update path; the release qualification also checks upgrading the published 1.2.0 installer.
- **Linux amd64:** install `Colosseum-1.3.0-linux-amd64.deb` on Ubuntu 24.04 or Debian 13. Updates are manual. Corresponding source provenance is included with the release.
- **macOS Apple Silicon preview:** requires macOS 26.1 or newer. Open `Colosseum-1.3.0-macOS-arm64.dmg` and drag Colosseum into Applications. The app and image are ad-hoc signed and not notarized. For the first launch, use System Settings → Privacy & Security → Open Anyway if macOS blocks the developer. Physical Mac playback and Gatekeeper acceptance are separate from CI packaging checks.
- Android remains on `android-v1.3.0-beta.1` and is not replaced by this desktop release.
- Vinyl and Feria remain unavailable in the desktop installers. Collections remain local; hosted sharing is deferred.

External sources and trackers are optional, independent services. Colosseum does not host media. Package checks do not establish live playback for every external provider.
