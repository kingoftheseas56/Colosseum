# Colosseum 1.1.5

## Streaming recovery

The Theatre stream path now fails closed when the bundled Stremio stream engine is missing or
cannot start. Colosseum reports:

> Streaming engine unavailable. Repair or reinstall Colosseum.

The player leaves its retry/switch loop, so a broken installation produces a clear recovery path
instead of repeatedly retrying a server that never became available. Requests queued during a
failed startup are discarded and cannot replay after the runtime is repaired or replaced.

## Release packaging

The canonical Windows installer continues to bundle the complete Stremio stream-server payload and
now has a release contract for the user-facing branding. Installer and uninstaller windows say
**Colosseum**, use the existing Colosseum icon, and retain `1.1.5` in the installer filename and
Windows application metadata.

## Verification

The stream failure path is covered by a real Qt test and the static runtime contract. The release
installer workflow builds from an exact `master` commit, checks the complete runtime payload,
fingerprints the installer, then performs a fresh install, boot, runtime-file, and uninstall smoke
test on Windows.
