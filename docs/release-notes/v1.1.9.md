# Colosseum 1.1.9

Release candidate: not published. This candidate starts at `v1.1.8` and includes
the catalogue delivery migration, Universes, shared reliability improvements,
the first-party updater migration, and the Linux candidate fixes. Feria and Vinyl
source is integrated behind Coming Soon; neither world is available in 1.1.9.
There is one standard edition, with optional accounts and local use.

## Online catalogues and content API

- Native manga/anime, Comics and Theatre catalogue reads use the content API and
  prepared query assets, avoiding whole-catalogue database downloads on those paths.
- Prepared landings, progressive shelves, smaller fact shards and deferred decoding
  reduce the work needed before useful catalogue content appears.
- Manga volume counts and BookWalker-sourced cover URLs travel through the catalogue
  service. Existing media-cover providers remain in use.
- Universe definitions and owned artwork use published online content, allowing
  compatible content updates without rebuilding the app.
- One Piece tribute artwork is fetched online and cached. Native add-on artwork and
  the existing 55-extension logo table remain bundled.
- Final production publication, installed-package checks and loading comparisons
  remain release gates; this candidate does not claim universal performance parity.

## Universes

- Universes is the fourth world, with franchise banners, category filters,
  keyboard navigation, and a separate Tributes carousel.
- Structured cross-media shelves cover James Bond, Marvel, Star Trek, Star Wars,
  DCAU, Avatar, Studio Ghibli, Shonen Jump, One Piece, Dragon Ball, Naruto, and
  Attack on Titan.
- One Piece includes the East Blue, Paradise, New World, and Final Sea atlases,
  interactive island markers, arc previews, sea navigation, and online artwork.
  Its standard Universe page carries the 56-work catalogue.
- Improved poster preloading, focus handling, artwork identities, and map placement.
- Shared TopBar navigation adapts to narrow windows and includes the Universes pill.

## Vault and Extensions

- Desktop Vault has a native media-library layout with browsing rails, poster cards,
  folder breadcrumbs, detail sheets, and the shared Colosseum theme.
- Extensions opens the native House page with rotating franchise wallpapers,
  a glass tray, and extension tiles. Chain, House, and Store navigation is connected.
  House banners use installed extension artwork with bundled offline fallbacks.

## Reading and reliability

- Continue reopens standalone local comics in the correct reader and assigns
  their identity before restoring saved reading progress.
- Fixed PDF text search and navigation in Reader2.
- Improved Theatre replay, audiobook final-chapter completion, progress flushing
  during profile departure/shutdown, and local-file identity across restarts.
- Improved account refresh recovery after timeouts and restarts, disabled avatar
  storage handling, unavailable trackers, shutdown ordering, and Windows helper cleanup.
- Linux fixes cover X11 sizing, WSLg placeholder screens, unavailable tracker guards,
  Reader2 test linkage, and the Watch Party shutdown crash. Portable packaging includes
  AppRun and dependency checks. A newly built 1.1.9 Linux package still needs qualification.

## Coming Soon and platform scope

- Feria and Vinyl remain blocked through normal and indirect world entry. Ordinary
  release builds ignore the Vinyl development environment opt-in.
- Feria services remain lazy while the world is disabled. Full browser and music
  feature qualification is deferred.
- Feria and Vault are permanently outside Android's scope. Android packaging excludes
  their desktop dependencies and desktop Vinyl QML.

## Updates

- Windows update discovery moves to `https://getcolosseum.world/updates/stable.json`,
  using the existing production signing trust and retaining signed legacy compatibility.
- Windows users on 1.1.8 need one manual installation of 1.1.9 to migrate. Later
  Windows releases can use the first-party feed. Linux remains manual-update-only.
- The stable feed must remain inactive until the real installer, matching signed
  manifest, downloadable release assets, and versioned release-notes page are verified.

Release gates still include installer packaging, production-key signing, public
asset verification, and an actual Windows installation/update-and-restart trial.
The existing 1.1.8 download flow is not changed by this source candidate.

## Testing and maintenance

- Expanded automated coverage for Universes, One Piece, Vault, account refresh,
  standalone comic Continue, PDF search, and release publishing.
- Improved QtWebEngine codec CI configuration and compiler caching.
- The source history includes Chocolatey metadata for the 1.1.8 Windows package.
  This does not publish a 1.1.9 Chocolatey package.
- Development guidance and canonical event-memory integration were updated.
- AniList, CloudStream, Aniyomi, and Nuvio integration feasibility was researched;
  these integrations are not shipped features of this release.
