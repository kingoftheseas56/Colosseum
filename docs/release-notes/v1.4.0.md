# Colosseum 1.4.0 — desktop release notes

Released November 22, 2026 for Windows and Linux, with an Apple Silicon macOS preview. This release rebuilds Vault as a title-based library, brings home-server libraries into Vault and Theatre, adds Smart Pick, and makes the Colosseum downloads folder movable.

The desktop installers use application source [`ab62d156e` (`v1.4.0`)](https://github.com/kingoftheseas56/Colosseum/commit/ab62d156efd2fa4c923de5970704f0860e086f23). [Downloads and checksums](https://github.com/kingoftheseas56/Colosseum/releases/tag/v1.4.0) · [Changes since 1.3.0](https://github.com/kingoftheseas56/Colosseum/compare/v1.3.0...v1.4.0)

## Vault and home servers

- **Browse by title.** Vault has a Home shelf, Movies, Shows, Books, Comics, and Unmatched. Related files can share one title, and Movies and Shows have genre filters. Local matching better handles release tags, numerals, folder names, and book title and author variants. If a file needs help, open **Match** from Unmatched. Use **File as extras** for videos that belong outside the main title shelves. [Vault overhaul](https://github.com/kingoftheseas56/Colosseum/commit/531a0e071)
- **Choose what to index.** When adding a source, open its subfolders and uncheck the files or folders you want Vault to skip. Use the source’s file picker to change those choices later. Excluded files stay on your drive and are skipped by the indexer. Forgetting a source removes it from Vault. The underlying files stay where they are. [Folder selection and scanning](https://github.com/kingoftheseas56/Colosseum/commit/9a7fe7397)
- **Follow a scan.** The first import displays progress in the Vault Home feature area. Later scans show progress above the shelves. Use **Stop scan** while the scan can be cancelled. This release reduces some delays during indexing and shelf refresh. Very large sources can still make Vault slow or unresponsive while it works.
- **Connect Jellyfin, Emby, or Plex.** Connect from Vault or Sync Center, browse the server’s movie and show libraries, and open a server copy in Theatre. The integration supports refreshing library listings and syncing playback progress. The release fixes Plex token verification and multi-page library browsing, Emby resume data, and external subtitle handoff from all three servers to the desktop player. Local fixtures exercised these paths. Live Plex and Emby checks remain open. [Home-server fixes and fixtures](https://github.com/kingoftheseas56/Colosseum/commit/4b92d4181)

## Theatre and video playback

- **Smart Pick** automatically selects a source when you press Play. The quality setting offers 1080p, 4K, and Off. The player can open and show the search in progress. Smart Pick can choose a suitable result while slower providers are still answering. If nothing passes the checks, the source list lets you choose manually. With Smart Pick off, Play opens manual selection. Next Episode reuses the current torrent when it contains the next episode and can use Smart Pick when another source is needed. [Smart Play integration](https://github.com/kingoftheseas56/Colosseum/commit/cf4500626) · [Source selection and fallback](https://github.com/kingoftheseas56/Colosseum/commit/4fbfd7c10)
- **Sources layout.** The list extends to the bottom of the window, with a smaller banner on shorter windows. [Sources layout](https://github.com/kingoftheseas56/Colosseum/commit/e4cb45536)
- **Fullscreen keyboard shortcuts.** The player keeps receiving playback keys when the controls fade. [Player focus fix](https://github.com/kingoftheseas56/Colosseum/commit/49ae5045d)

## Tankoban, Biblio, and readers

- **Tankoban.** Newly completed manga chapters are saved as individual CBZ archives. Existing chapter folders can still open in the reader. Live Reading remains an opt-in way to open pages while a chapter is downloading. Nyaa lookup handles hyphenated titles more reliably. GetComics issue downloading is opt-in. [CBZ downloads](https://github.com/kingoftheseas56/Colosseum/commit/c9e085ca6) · [Nyaa search](https://github.com/kingoftheseas56/Colosseum/commit/1a7718407)
- **Biblio.** Book pages restore audiobook lookup and listening from a local copy. AudioBookBay lookup retries transient errors, and native audiobook downloads are wired on Windows. AudioBookBay acquisition and Tankorent ebook sources require opt-in. [Book-page listening](https://github.com/kingoftheseas56/Colosseum/commit/2721bbbac) · [Windows audiobook downloads](https://github.com/kingoftheseas56/Colosseum/commit/1d759d167) · [Source opt-ins](https://github.com/kingoftheseas56/Colosseum/commit/3f414dec2)
- **EPUB reader.** Keyboard navigation has clearer focus, and the reading controls can hide after a mouse click once the reader is idle. [Reader keyboard focus](https://github.com/kingoftheseas56/Colosseum/commit/56e8799c5) · [Idle controls](https://github.com/kingoftheseas56/Colosseum/commit/14b5f9a60)

## Downloads

New managed downloads go under the system Downloads folder in `Colosseum` by default. The desktop layout uses readable names in media folders such as `Manga`, `Comics`, `Books`, `Audiobooks`, `Movies`, and `TV`. **Change download location** on the Downloads page shows the old and new locations, item count, size, and naming collisions before moving managed files. Choose **Move** to confirm. [Movable download location](https://github.com/kingoftheseas56/Colosseum/commit/b07356b0b)

## Home, dock, Universes, and Collections

- **Home and dock.** The redesigned dock opens a full-width picker for worlds, featured titles, Tributes, and utilities. Desktop utilities such as Wallpaper and DLNA are reachable from the picker, while Updates is in the header. Closing Downloads or Collections with a mouse click on its dock icon clears the pointer focus state. [Dock and picker integration](https://github.com/kingoftheseas56/Colosseum/commit/5725866c3) · [Dock focus fix](https://github.com/kingoftheseas56/Colosseum/commit/53c6751de)
- **Universes and Tributes.** The existing franchise catalogues remain in Universes. Tributes are also reachable from the launcher’s Tributes deck, and the Cosmere card uses bundled artwork. [Tributes in the launcher](https://github.com/kingoftheseas56/Colosseum/commit/1cfd428a3) · [Cosmere art](https://github.com/kingoftheseas56/Colosseum/commit/37001437a)
- **Collections** remain local and open from the dock. **Vinyl** and **Feria** are visible as disabled **SOON** entries on desktop.
- **App tooltips.** The temporary tooltip rollout, including Android press-and-hold, was removed before the tag. [Tooltip removal](https://github.com/kingoftheseas56/Colosseum/commit/c924b85b2)

## Account, Sync Center, and Extensions

- **Accounts and sync.** Core local use works without signing in. Existing Colosseum account, tracker, and Theatre provider routes remain available subject to platform support and setup. Sync Center adds home-server connection and library refresh alongside the existing sync controls. [Home-server connection](https://github.com/kingoftheseas56/Colosseum/commit/8c3e3963d)
- **Extensions.** Open Extensions in the top bar for redesigned discovery, categories, and Installed management. Nuvio repositories are available through a drawer on supported builds. Optional Essentials such as Torrentio, OpenSubtitles, Nyaa, Tankoyomi, and LibGen require explicit installation on a fresh profile. Existing installed choices are retained. [Extensions redesign](https://github.com/kingoftheseas56/Colosseum/commit/5725866c3) · [Optional Essentials](https://github.com/kingoftheseas56/Colosseum/commit/076356bea)

## Android parity checklist

The published Android package for this release cycle is [Android 1.3.0 Beta 2](https://github.com/kingoftheseas56/Colosseum/releases/tag/android-v1.3.0-beta.2). Android 1.4.0 candidates require their own package and device evidence. Record the exact APK commit and build ID, then mark each journey **verified on device**, **missing or failing**, or **intentionally platform-specific**. Use `Unverified` where nobody has run the exact build.

| Surface | Compare against the desktop baseline |
| --- | --- |
| Home, dock, top bar | Open the launcher and a world, return Home, switch sessions, and toggle Downloads and Collections. Check touch scrolling and short landscape. Track any candidate-specific top-bar placement and press-and-hold session close independently. |
| Theatre and player | Try Play with Smart Pick enabled and disabled, selection with slow providers, the fallback list, and Next Episode. Check sources, audio/subtitles, and playback controls after the HUD hides. Exercise touchscreen controls and any supported keyboard/remote. |
| Tankoban and comic reader | Download a chapter, verify its saved format, then open and resume it. Separately exercise opt-in Live Reading and an existing downloaded chapter. |
| Biblio and readers | Open and resume a local EPUB, check the reading controls, and try book-page audiobook lookup, download, and local listening where offered. The Android ebook renderer serves the role of the desktop WebEngine paper view. |
| Universes and Tributes | Open a franchise, an item or issue from its catalogue, and a Tribute. Check return navigation. |
| Vault and home servers | Add a source, exclude a nested folder, observe scan progress, and match and open a local title. Switch worlds during a large scan and reopen Vault. Check each offered server’s connect, refresh, playback, resume, and external subtitles separately. |
| Downloads | Verify the actual path and on-disk filename. Where relocation is offered, check preview, cancel, confirmation, and opening the file afterwards. Rate desktop folder relocation separately from basic Android downloading. |
| Account and Sync Center | Check guest use, sign-in and account input with the on-screen keyboard, then open Sync Center and test each configured provider separately. |
| Extensions | Check discovery and Installed views, explicit installation on a fresh profile, and whether an installed source appears in the expected world. |

### Platform and source boundaries

- At the desktop tag, Android packages the Vault button as shared UI and excludes the Vault world and backend, Feria, Vinyl, the optional Windows Player 2, and the desktop WebEngine ebook paper view. Download-folder relocation is wired on desktop. The Android Vault candidate adds its own all-files-access route and needs its own checks. [Tagged Android packaging](https://github.com/kingoftheseas56/Colosseum/blob/v1.4.0/native/cmake/android.cmake) · [Tagged desktop download location wiring](https://github.com/kingoftheseas56/Colosseum/blob/v1.4.0/native/main.cpp#L535)
- The tag includes Android-specific layout changes, a full-window Sources sheet, Smart Pick loading feedback in the Android player, account field handling above the keyboard, and public tracker hints in magnets for Android streams. These are source findings. The OnePlus check should cover browsing and closing the Sources sheet, slow-provider fallback, and a cold torrent start with a known healthy test swarm. [Full-window Sources](https://github.com/kingoftheseas56/Colosseum/commit/f4314fc07) · [Player loading feedback](https://github.com/kingoftheseas56/Colosseum/commit/e9f05f81f) · [Tracker hints](https://github.com/kingoftheseas56/Colosseum/commit/f45d9c979)
- Android long-press-to-close for minimized sessions and the later Android top-bar rearrangement belong to candidate work after the desktop tag. The tag does include the desktop dock redesign and pointer-focus fixes.
