# WT-03 — Android decoder compatibility annotations and soft ranking are not consumed

Class C; priority P2. Authorization/order comes from START.md, not classification alone.

## Why this matters
Users get less guidance before selecting sources likely unsupported by their decoder; no claim hints predict every successful/failed decode.
