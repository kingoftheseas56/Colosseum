# WT-04 — Android system text-size preference no longer reaches shared UI text

Class C; priority P2. Authorization/order comes from START.md, not classification alone.

## Why this matters
Increasing Android system font preference does not enlarge these custom pixel-sized labels through the retained native preference path.

## Alpha behavior
Theme reads PlatformRuntime.fontScale only on Android and fontSize(base) scales typography; many QML consumers use it.

## Beta behavior
Theme has no fontScale/fontSize and consumers use raw pixel sizes although native configuration bridge still exists. Density zoom is separate from system text preference.

## Actual owner/caller
Android Activity fontScale notification -> PlatformRuntime -> missing Theme consumer -> common UI labels. Does not establish ebook content font behavior, which has separate reader settings.
