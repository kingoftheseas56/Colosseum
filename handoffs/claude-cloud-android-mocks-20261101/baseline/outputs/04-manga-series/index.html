04 · Manga series / chapter selectors

Two local, interactive fitting studies made against the approved Colosseum QML. They are layout mockups, not product changes or Android runtime verification.

manga-series.html — Reading Room / Tankoban Mode

One Piece header, synopsis more, library / collection actions, ON THIS DEVICE progress, cover-flow, focus action, Select and batch actions.

manga-chapters.html — Chapter Mode

Shared series header and mode switch, original language dropdown, saved chapter action, chapter range/page dropdown, Go to chapter and download controls.

Both pages include editable portrait, landscape, narrow, tablet and desktop viewports plus safe-area insets and font scale outside the mock. Use ?capture=1 for an unframed 1:1 screenshot at the browser viewport; add &state=language-open, page-open, selected or expanded to exercise states.

All artwork points to the frozen local reference. No exact One Piece manga-volume cover or chapter-thumbnail files are present in that frozen asset list; titled One Piece universe artwork is used as a visible illustrative stand-in, documented in FIDELITY.md. See REPORT.json for verification and limitations.
