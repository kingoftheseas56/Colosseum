These static files were retrieved for the local Batch 5 mock from the KDE paths named by frozen WallpaperApi.js. They are unchanged upstream images. The browser loads only local copies. Source code names, artist and license strings below are transcribed from WallpaperApi.js; exact fetch URLs, ETags, byte counts and SHA-256 hashes are in ../../evidence/kde-assets.json.
