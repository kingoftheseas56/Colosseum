1. `todo list` (or read `.pi/todos/`) — pick OPEN todos; respect BLOCKED BY.
2. Per unblocked item spawn ONE background agent, deepseek model
   (`deepseek/deepseek-v4-pro` for implementation, `-flash` for docs):
   `background_agent(cwd=/Volumes/workplace/Colosseum, model=…, prompt=<todo body> + parallel-safety + "do NOT git commit or close the todo — orchestrator gates" )`. Max 4 concurrent agents; disjoint file ownership is designed in.

   `git add` ONLY that item's owned files, commit with a message referencing
   the todo id, close the todo via the todo tool. Never `git add -A`.
4. Wave structure: wave-1 (closed), player work (closed). Current open wave:
   Phase A (parity spine) — see queue below.

## Architecture map (contracts are the boundary)

- crates/catalog — SQLite series store + search (rusqlite, bundled)
- crates/account — Go-port domain: create/sign-in/refresh, argon2id,
  Go error codes; in-memory store (persistence = roadmap slice 4)
- crates/daemon — composition root: axum HTTP, directories-crate paths,
  data dir `io.Brotherhood.Colosseum`; maps domain errors to the Go
  envelope {"error":{code,message}}
- crates/player — `Player` trait (pull: load/play/pause/seek/position/
  duration/next_frame/event); `native()` factory; avfoundation backend
  (AVAssetReader→BGRA VideoFrame). NOT Send (objc thread affinity).
- crates/ui-gpui — GPUI 0.2.2 shell: daemon HTTP via gpui_tokio bridge +
  reqwest (tokio island); frames → RenderImage (BGRA on the wire, no
  channel swap) at a timer-driven 10ms pump.
- rules: deps flow daemon→{catalog,account}, ui-gpui→player; domains never
  see axum/tokio/http; docs/rust-poc.md records every decision.
